# SolidWorks学习总结
 ##  练习内容
 1. **二维草图基础绘图练习**
 完成多种基础草图轮廓绘制：圆形、多边形、长圆孔、U型圆弧、圆角矩形、倒角矩形以及异形卷曲轮廓。练习直线、圆弧、多边形绘图命令。
 2. **草图修改与编辑工具练习**
 学习使用**等距实体、实体引用**；运用智能尺寸完成尺寸标注；添加各类几何约束，区分欠定义草图与完全定义草图；练习圆角、倒角草图修改。
 3. **旋转凸台三维建模练习**
 绘制封闭截面草图，以中心线作为旋转轴，使用旋转凸台生成盘类回转实体；修改草图尺寸，体会参数化建模，草图改动之后三维模型同步更新。
 ##  所学知识点
 - 草图绘图：基础几何图形绘制；中心线既可以作为绘图定位基准，也可以充当旋转特征的回转轴线。
 - 草图编辑：**实体引用可以直接复用已有模型边线生成草图；等距实体用来快速生成偏移轮廓；智能尺寸完成尺寸约束**。
 - 三维建模：旋转凸台适合轴类、盘类回转零件建模；草图驱动实体，修改草图尺寸联动更新三维模型。
 ##  后续学习计划
 继续加强草图约束练习，尽量做到草图完全定义；熟悉拉伸、旋转特征的适用场景；尝试临摹工程图纸进行零件建模练习。
