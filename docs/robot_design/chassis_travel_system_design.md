## 1. 行走方式选型：轮子 vs 履带

### 1.1 功能描述

底盘行走系统是机器人的基础，负责承载整车重量、提供移动与转向能力，并满足比赛场地对爬坡、越障、过桥的硬性要求。本系统的核心目标是：**在5分钟比赛时间内，稳定通过150mm桥梁，并完成地面与高台区域之间的移动。**

### 1.2 第一版选型：为什么最初选择履带？

**第一步：从场地限制反推底盘需求**

比赛场地的关键地形包括：
- 300mm高台，坡比0.5，约26.6°坡度
- 150mm台阶
- 150mm宽桥梁

这意味着底盘必须同时满足三个条件：
1. 能爬26.6°坡；
2. 能上150mm台阶；
3. 整车宽≤150mm，才能通过桥梁。

**第二步：轮式与履带式的能力对比**

| 对比维度 | 轮式 | 履带式 | 对本比赛的影响 |
|---|---|---|---|
| 稳定性 | 一般。越障和急转时容易侧翻 | 较好。接地面积大、重心低，姿态可控 | 履带更适合高台和桥梁边缘行驶 |
| 爬坡能力 | 较弱。轮胎接触面积小，坡度稍大就打滑 | 较强。接地面积大、抓地力强，能适应较陡坡面 | **这是选型的核心决定因素** |
| 越障能力 | 受轮径限制，跨越150mm台阶非常困难 | 可跨越较小台阶和沟槽，地形适应性强 | 履带能过150mm台阶，轮式需要极大轮径 |
| 转向灵活性 | 好，可原地转向或小半径转向 | 一般，靠两侧差速转向，摩擦大、阻力高 | 轮式更灵活，但履带可接受 |
| 结构复杂度 | 较低，结构简单、易装配维护 | 较高，涉及履带、驱动轮、张紧轮、负重轮等 | 履带代价更大，但值得 |
| 速度 | 较快 | 相对较慢 | 本比赛5分钟，速度不是主要瓶颈 |
| 成本/维护 | 较低，轮胎易更换 | 较高，履带易磨损、需张紧调整 | 履带维护成本高，但在预算内 |

**第三步：为什么“爬坡能力”是决定性指标？**

比赛的关键得分区域（中央高台、对方高台）只能通过桥梁和坡道到达。如果底盘爬不上坡、过不了桥，机器人就被限制在地面区域，得分上限被大幅压低。

轮式在坡比0.5的坡面上，由于轮胎与地面的接触面积小、摩擦力不足，很容易打滑。而履带与地面的接触面积大，在同样的坡面上不易打滑，越障时姿态也更可控。

**第四步：履带方案的代价与接受理由**

履带并非没有缺点：结构更复杂、转向阻力大、速度偏慢、维护成本更高。但综合比赛任务需求：
- 爬坡能力是硬性门槛，轮式风险太高；
- 速度不是主要瓶颈，5分钟内完成6-9个方块的收集即可；
- 结构复杂度在可接受范围内，团队有3D打印和装配能力。

**第一版结论**：综合稳定性和爬坡能力两项关键指标，团队初步选择**履带式行走方案**。后续因电控技术原因，该方案被迭代为麦克纳姆轮方案，详见第5章。

## 2. 底盘尺寸与过桥校核

### 2.1 功能描述

底盘尺寸必须满足比赛规则中的初始尺寸限制，同时要通过150mm宽的桥梁。本板块记录了尺寸的校核过程，以及为什么最终把车宽压缩到130mm。

### 2.2 开发历程：为什么车宽必须压缩到130mm？

**第一版尺寸方案（185mm车宽）**

在底盘方案确定后，我们曾按常规思路设计了一版履带底盘：
- 履带中心距150mm，履带单条宽35mm；
- 整车宽度 = 150 + 35 = 185mm；
- 规则允许的整车宽度上限是195mm，185mm在规则范围内。

**暴露的致命问题**

在对照《2026CRTC参赛手册V1.4》第16页场地数据时，我们发现了一个致命遗漏：**比赛场地的桥梁模块宽度仅为150mm**。

185mm > 150mm，意味着这款底盘**根本无法通过桥梁**，也就无法前往中央高台和对方高台区域收集方块。

**为什么要改？**
- **场地限制**：桥梁是连接高台与高台、抢夺中央高地黄色能量核心的**唯一通道**。如果不能过桥，机器人就被限制在了地面区域，得分上限被大幅压低。
- **操作风险**：即使勉强过桥，185mm的车宽在150mm桥面上，单侧仅余-17.5mm（车比桥还宽），机器人会直接卡在桥头或坠落。

**第二版尺寸方案（130mm车宽）**

为了解决过桥问题，团队进行了彻底的尺寸重构：
- 履带中心距从150mm压缩至95mm；
- 整车宽度 = 95 + 35 = 130mm；
- 单侧余量 = (150 - 130) / 2 = 10mm，可安全直线通过。

**尺寸压缩带来的连锁调整**：
- 履带内侧净距从115mm缩减为60mm；
- 十字拨轮轴向长度从110mm缩短至55mm；
- 收集盒内部宽从90mm缩小至55mm；
- 所有轮轴、车架底板、拨轮支架重新设计。

### 2.3 尺寸校核结果

| 项目 | 设计尺寸 | 规则上限 | 判定 |
|---|---|---|---|
| 整车初始长 | 280 mm | ≤290 mm | ✅ |
| 整车初始宽 | 130 mm | ≤195 mm | ✅ |
| 整车初始高 | 200 mm | ≤210 mm | ✅ |
| 桥梁通过性 | 130 mm < 150 mm | 桥宽150 mm | ✅ |
| 重量 | 目标≤1.8 kg | ≤2.0 kg | ✅ |
| 供电模块 | 1个，输出接口1个 | 仅允许1个 | ✅ |

## 3. 两台机器人的底盘差异

### 3.1 功能描述

根据9月30日组会决定，团队制作两台机器人，分工不同。底盘作为共同平台，需要在统一方案的基础上，根据两台车的任务差异做微调。

### 3.2 分工与底盘差异

| 项目 | 一号车（地面快速收集） | 二号车（高台精准收集） |
|---|---|---|
| 主要任务 | 平台、地面方块快速收集 | 高处置物架、附属高台方块收集 |
| 底盘方案 | 履带式，中心距95mm | 履带式，中心距95mm |
| 驱动电机 | TT马达1:120 ×2 | TT马达1:120 ×2 |
| 重心位置 | 偏前，方便快速转向 | 偏中，方便高台稳定 |
| 额外机构 | 无 | 可加装辅助抬升/伸展机构（后续迭代） |

## 4. 第二辆车辅助机构：滑轨与叉车结构

### 4.1 功能描述

第二辆车主要负责**中央高台上的方块、置物架上穿着的方块、洞里的方块**。与第一辆车“快速扫地面”的任务不同，第二辆车需要更精细的操作能力：能够伸缩、旋转、叉取方块，并且能在高台和置物架之间灵活移动。

### 4.2 开发历程：为什么选择叉车+滑轨结构？

**任务需求分析**

第二辆车面对的场景有三个：
1. **中央高台上的方块**：位置较高，需要够到并一次性叉住多个；
2. **置物架上穿着的方块**：位置刁钻，需要灵活旋转的叉子撸下来；
3. **洞里藏着的方块**：需要长叉子伸进洞里勾出来。

这三种场景对机构的要求分别是：**伸缩、旋转、长臂**。

**方案对比与选择**

| 方案 | 优点 | 缺点 | 是否采用 |
|---|---|---|---|
| 收集盒式 | 结构简单，与一号车一致 | 无法够到高处和洞里 | 否 |
| 叉车+滑轨 | 可伸缩、可旋转、可勾取 | 结构复杂，控制难度高 | **是** |
| 单独设计干扰车 | 可干扰对方行动 | 速度要求太高，来不及 | 否 |

**为什么放弃“干扰车”方案？**

团队曾讨论是否单独设计一辆车干扰对方行动。但比赛只有5分钟，如果车辆速度不够快，干扰效率太低，反而浪费了一辆车的得分机会。最终决定：**两台车都专注收集，放弃干扰策略。**

**第二辆车最终方案**

- **上部**：四齿叉车结构，开局直行一次叉住高台上4个方块；
- **中部**：灵活叉子，撸掉置物架上的方块；
- **下部**：长端叉子，把洞里的方块勾出来；
- **舵机配置**：下三个叉连在一起，用2个舵机控制；最上面的叉用2个舵机，便于灵活旋转；
- **滑轨**：不需要收集盒，叉子设计足够长，通过滑轨实现前后伸缩和左右移动；
- **滑轨技术路线**：经deepseek指导，初步决定使用**传送带结构**，具体实现待后续完成。

## 5. 迭代记录：从履带方案切换到麦克纳姆轮方案

### 5.1 迭代触发原因：电控技术困难

在第一版履带式底盘进入电控联调阶段后，团队遇到了一个无法在短时间内跨越的技术障碍：**履带差速转向的控制逻辑难以调通。**

具体表现：
- 两侧履带电机通过DRV8833驱动，在直行时基本正常；
- 但在需要转向时，左右两侧履带的PWM占空比和方向配合很难调平；
- 遥控操作时，操作手推杆转向，机器人经常出现“一侧动一侧不动”“原地打转过度”或“转向滞后”等现象；
- 团队电控成员对差速转向的PID调节和死区补偿经验不足，调试时间有限。

由于中期考核临近（10月19日），团队决定放弃履带方案，改用**麦克纳姆轮（麦轮）**方案。

### 5.2 为什么选择麦克纳姆轮？

麦克纳姆轮是一种全向轮，通过四个轮子的速度矢量合成，可以实现：
- 前后移动；
- 左右平移；
- 原地自转；
- 任意方向斜行。

**核心优势**：麦轮的运动学解算是**开环**的，不需要依赖复杂的PID反馈调节。只要按逆运动学公式给四个轮子分配正确的PWM值，机器人就能按预期方向移动。这对新生组来说，比履带差速转向更容易上手。

| 模块2 | 右前麦轮 | 右后麦轮 |
| 模块3 | 十字拨轮电机 | （空置） |

// 设 vx = 前后速度，vy = 左右平移速度，ω = 旋转角速度

v_fr = vx + vy + ω * (L + W);
v_rl = vx + vy - ω * (L + W);
v_rr = vx - vy + ω * (L + W);
PS2手柄映射：

左摇杆左右 → 左右平移；

5.5 对原设计的影响与保留部分
保留不变的部分：

十字拨轮收集机构（Φ130mm，轴向55mm，轴心距地65mm）；

弧形导流板与收集盒（内部140×55×90mm，入口底部距地65mm）；
