## 1. 设计总览

### 1.1 设计目标

| 目标 | 说明 |
|---|---|
| 通过性 | 能上300mm高台（坡比0.5）、150mm台阶、桥梁下方净高130mm |
| 收集效率 | 5分钟内扫入6-9个30mm白色能量单元 |
| 稳定性 | 从180mm自由落体无零件掉出 |
| 成本 | 两台总成本控制在400元内 |
| 重量 | 每台≤1.8kg，留200g余量 |
| 尺寸 | 初始长≤290，宽≤195，高≤210mm |

### 1.2 系统组成

```text

机器人
├── 底盘系统
│   ├── 履带 ×2
│   ├── 驱动轮 ×2
│   ├── 从动轮 ×2
│   ├── 轮轴 ×4
│   ├── 轴承 ×8
│   └── TT马达1:120 ×2
├── 收集系统
│   ├── 滚筒（直径60，长110）
│   ├── 滚筒轴
│   ├── TT马达1:48 ×1
│   ├── 导流板（35°）
│   └── 收集盒（120×105×80）
├── 辅助系统
│   ├── SG90舵机 ×1（挡板）
│   └── 软硅胶挡板
└── 电控系统
├── STM32F103C8T6
├── DRV8833 ×2
├── PS2手柄+接收器
├── 无线继电器
├── DC-DC降压模块
└── 18650电池 ×2

```

### 1.3 设计原则

1. **低质心**：电池、主控、驱动放在履带之间、滚筒后方，距地60-80mm。
2. **低入口**：收集盒入口底部距地25-35mm，方块不需要爬高。
3. **模块化**：滚筒、收集盒、导流板均可独立拆卸更换。
4. **可维护**：线路走线槽，杜邦线用扎带固定，避免脱落。
5. **轻量化**：3D打印件壁厚1.5-2mm，非受力件用PLA，受力件用PETG。

| 项目 | 规格 |
|---|---|
| 型号 | SG90 |
| 数量 | 1个/台 |
| 功能 | 收集盒后壁挡板开合 |
| 安装 | 3D打印舵机支架 |
| 控制 | STM32 PWM |
| 作用 | 防止爬坡/颠簸时方块掉出 |

### 5.4 收集盒防掉设计

1. **后壁软硅胶挡板**：高30-40mm，方块进去后自动回弹。
2. **底板倾斜**：方块进入后自然滚向最里面。
3. **顶部半封闭**：只留滚筒入口，防止方块从上方掉出。
4. **侧壁光滑**：贴特氟龙胶带，减少摩擦。

### 6.3 接线定义

| STM32引脚 | 功能 | 连接 |
|---|---|---|
| PA0 | PWM | 左履带DRV8833 IN1 |
| PA1 | PWM | 左履带DRV8833 IN2 |
| PA2 | PWM | 右履带DRV8833 IN1 |
| PA3 | PWM | 右履带DRV8833 IN2 |
| PA4 | PWM | 滚筒DRV8833 IN1 |
| PA5 | PWM | 滚筒DRV8833 IN2 |
| PA6 | PWM | SG90舵机 |
| PA7 | SPI | PS2接收器 |
| PA8 | GPIO | 无线继电器控制 |

### 6.4 供电模块规则

- 每台机器人**仅1个供电模块**，有且仅有一个输出接口。
- 电池盒输出→无线继电器→主控/驱动，算1个供电模块。
- 不要加转接板变成多个接口。
- 无线继电器接在电池与底盘电源之间，确保10m内能切断底盘电源。

## 8. 供电与安全

### 8.1 电源规格

| 项目 | 规格 |
|---|---|
| 电池 | 18650 ×2串联，7.4V |
| 容量 | 2000-3000mAh |
| 放电倍率 | ≥5C |
| 供电模块 | 1个，输出接口1个 |
| 降压 | 7.4V→5V，给主控和舵机 |
| 电机供电 | 7.4V直供DRV8833 |

### 8.2 安全规范

1. 电池不得短路、反接、过放。
2. 无线继电器必须能在10m内切断底盘电源。
3. 线路不得过度裸露，用扎带固定。
4. 不得携带尖锐物体、易燃易爆化学物质。
5. 不得加装易损坏对方机器人的装置。

### 8.3 检录要求

- 机器人从150-200mm自由落体，无零件掉出。
- 无线继电器断电功能正常。
- 尺寸、重量符合规范。
- 供电模块数量正确。

## 10. 装配流程

### 10.1 装配顺序

```

1. 车架底板打印完成
2. 安装履带轮系（驱动轮、从动轮、轴承、轴）
3. 安装履带，调节张紧
4. 安装TT马达1:120 ×2，连接驱动轮
5. 安装滚筒支架、滚筒轴、滚筒主体
6. 安装TT马达1:48，联轴器连接滚筒
7. 安装导流板
8. 安装收集盒、舵机、挡板
9. 安装电控板、电池、主控、DRV8833
10. 接线、调试
11. 整机测试

```

### 10.2 装配注意事项

1. 履带张紧度：中部下垂≤5mm。
2. 滚筒与导流板间隙：5-8mm，必须过40mm方块。
3. 收集盒入口底部距地：25-35mm。
4. 线路用扎带固定，避免卷入履带或滚筒。
5. 电池固定在车架中心，远离滚筒和履带。
