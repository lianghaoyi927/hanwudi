# 第一版设计思路：滚轮式履带收集机器人

## 一、设计背景与目标

**比赛目标**：在5分钟对局中，尽可能多地收集地面白色能量单元（30mm/40mm方块）。

**设计定位**：第一版原型机，采用**橡胶履带底盘 + 横向圆柱滚轮 + 后方收集盒**的布局。

**核心诉求**：结构尽可能简单可靠，优先验证底盘通过性（能上高台、过桥梁），并测试最基础的扫块收集逻辑，为后续迭代提供试验数据。

## 二、整车尺寸与底盘规划（基于过桥约束）

根据《2026CRTC参赛手册V1.4》第15-16页场地尺寸，桥梁宽度为 **150mm**。为了能上桥收集高台上的方块，整车宽度必须严格压缩。

| 项目         | 尺寸                 | 备注                              |
|:---------- |:------------------ |:------------------------------- |
| **整车初始长**  | ≤280mm             | 规则限制：≤290mm                     |
| **整车初始宽**  | ≤135mm             | 规则限制：≤195mm（实际按过桥要求压缩）          |
| **整车初始高**  | ≤200mm             | 规则限制：≤210mm                     |
| **履带单条宽**  | 35mm               | 标准橡胶履带                          |
| **履带中心距**  | 95mm               | 外宽 = 95 + 35 = 130mm，可通过150mm桥梁 |
| **履带内侧净距** | 60mm               | 95 - 35 = 60mm（滚轮和收集盒的安装极限空间）   |
| **轮系**     | 18齿驱动轮/从动轮，轴距152mm | 节距12.7mm，42节履带，总长533.4mm        |

## 三、核心收集机构：横向滚轮设计

**收集逻辑**：利用滚轮的旋转摩擦力，将地面的方块顺着导流板“卷”入后方收集盒。这一设计的好处是结构极其简单，不需要复杂的联动机构。

| 部件         | 尺寸                | 说明                        |
|:---------- |:----------------- |:------------------------- |
| **滚筒外径**   | Φ60 mm            | 表面包裹2mm硅胶软管，增加摩擦力         |
| **滚筒长度**   | 55 mm             | 适配履带内侧净距60mm，两侧各留2.5mm防摩擦 |
| **滚筒轴心距地** | 55 mm             | 滚筒底部离地约25mm，刚好覆盖方块中下部     |
| **驱动电机**   | TT马达 1:48 ×1      | 转速约200rpm，表面线速度约0.63m/s   |
| **转向**     | 从右侧看**逆时针**旋转     | 下沿向后转，把方块往车尾卷             |
| **导流板**    | 宽55mm，长80mm，倾角35° | 连接滚筒后方与收集盒入口              |
| **收集盒**    | 内部 160×55×90mm    | 底板向后上方倾斜15°，后壁加软硅胶挡板      |

## 四、动力与电控方案

| 系统       | 选型                         | 备注                  |
|:-------- |:-------------------------- |:------------------- |
| **履带驱动** | TT马达 1:120 ×2 + DRV8833 ×2 | 左右独立驱动，差速转向         |
| **滚轮驱动** | TT马达 1:48 ×1 + DRV8833 ×1  | 单向旋转，负责卷块           |
| **主控**   | STM32F103C8T6              | 官方指定主控              |
| **遥控**   | PS2无线手柄（可对频锁定款）            | 左摇杆控制履带，L1/L2控制滚轮启停 |
| **电源**   | 18650电池 ×2串联（7.4V）         | 每台仅允许1个供电模块         |

## 五、第一版设计的局限性（为迭代铺路）

> ** 设计预判：**
> 在建模和测试前，我们预判这一版会存在以下问题，需要在实际测试中重点验证：

1. **对硬质方块的“推块效应”**：比赛和中期考核的方块是**硬质的**，且边长40mm，对角线达56.5mm。滚轮底部离地25mm时，接触点较高，极易将方块**往前推**，而不是往后卷。
2. **极易卡死**：滚轮与导流板之间的间隙如果小于65mm，40mm方块会直接卡死在这里，导致TT马达堵转烧毁。
3. **动平衡缺失**：实心圆柱滚筒在高速旋转时震动较大，对轴承寿命有影响。

## 六、下一步迭代方向（V2.0）

基于以上局限性，我们决定在第二版中放弃“圆筒滚轮”，改用**“十字形扇叶拍打机构”**。

- **原因**：十字叶片利用旋转的**瞬间冲击力**，克服硬质方块的静摩擦力，直接将其“拍”进收集盒，完美解决“推块”问题。
- **尺寸迭代**：受限于60mm的内侧净距，十字扇叶轴向长度定为55mm。
- **收集盒优化**：收集盒入口高度提升至65mm，增加弧形导流挡板，防止方块被拍飞。

# 第二版设计思路：十字拨轮履带式收集机器人

## 一、设计背景与迭代动机

在第一版（滚轮式）原型的设计中，我们预判圆筒滚轮会因接触点过高、摩擦力不足，导致40mm硬质方块被“推着走”而无法被有效卷入收集盒，且实心滚筒高速旋转时的震动较大。

为了解决“推块”和“卡死”问题，我们在第二版中放弃了圆筒滚轮，改用**十字形扇叶拍打机构**。我们期望利用十字叶片旋转时的**瞬间冲击力**，克服硬质方块的静摩擦力，直接将方块“拍”进后方收集盒。

## 二、核心改进：十字拨轮机构设计

十字拨轮是本版设计的核心，尺寸规划如下：

| 部件          | 尺寸           | 说明                   |
|:----------- |:------------ |:-------------------- |
| **十字外接圆直径** | Φ130 mm      | 叶片末端旋转轨迹             |
| **叶片径向半径**  | 65 mm        | 从轴心到叶片末端             |
| **叶片数量**    | 4片           | 十字形，严格对称保证动平衡        |
| **叶片厚度**    | 3-4 mm       | 根部4mm，末端3mm，TPU软胶材质  |
| **轴向长度**    | 110 mm       | 适配当时的履带内侧净距115mm     |
| **轴心距地**    | 65 mm        | 叶片末端刚好触地，能拍起40mm方块   |
| **驱动电机**    | N20 1:50金属齿轮 | 扭矩2-3kg·cm，防止拍打方块时堵转 |
| **转动方向**    | 从右侧看逆时针旋转    | 下沿向后拍打，把方块往收集盒方向送    |
| **弧形挡板**    | 半径约80mm      | 接住被拍飞的方块，导入收集盒       |

## 三、收集盒与整机参数

| 项目            | 尺寸     | 备注                     |
|:------------- |:------ |:---------------------- |
| **收集盒内部长**    | 160 mm | 可容纳4个40mm方块            |
| **收集盒内部宽**    | 90 mm  |                        |
| **收集盒内部高**    | 90 mm  |                        |
| **收集盒入口底部距地** | 65 mm  | 与十字扇叶轴心齐平              |
| **收集盒入口高度**   | ≥65 mm | 保证40mm方块（对角线56.5mm）能通过 |
| **底板倾斜**      | 15°    | 方块进去后自动滚向车尾            |
| **整车初始长**     | 280 mm | 符合规则≤290mm             |
| **整车初始高**     | 200 mm | 符合规则≤210mm             |

## 四、暴露的核心问题（致命缺陷）

在完成V2.0的三维建模和尺寸校核后，我们对照《2026CRTC参赛手册V1.4》第16页的场地数据，发现了一个致命的遗漏：

> **比赛场地的桥梁模块宽度仅为 150mm。**

而我们第二版设计的**整车宽度为 185mm**（履带中心距150mm + 履带单条宽35mm）。

**185mm > 150mm**，这导致我们这款十字拨轮履带车**根本无法通过桥梁**，也就无法前往中央高台和对方高台区域收集方块。这是一个在设计初期没有充分结合场地尺寸而导致的重大方案缺陷。

## 五、问题分析：为什么“宽”是致命的？

1. **场地限制**：比赛场地上的桥梁是连接高台与高台、抢夺中央高地黄色能量核心的**唯一通道**。如果不能过桥，机器人就被限制在了地面区域，得分上限被大幅压低。
2. **规则限制**：整车宽度的规则上限是195mm，我们原设计185mm虽然在规则允许范围内，但不符合“通过150mm宽桥梁”的实际赛场需求。
3. **操作风险**：即使勉强过桥，185mm的车宽在150mm桥面上，单侧仅余-17.5mm（车比桥还宽），机器人会直接卡在桥头或坠落，严重影响比赛进程。

## 六、下一步迭代方向（V3.0）

基于V2.0的失败教训，我们决定在第三版中进行**彻底的尺寸重构**：

- **缩小整车宽度**：将履带中心距从150mm压缩至 **95mm**。
- **新整车宽度**：95 + 35 = **130mm**，留出20mm单侧余量，确保能安全通过150mm宽的桥梁。
- **自适应调整核心机构**：
  - 十字扇叶轴向长度：从110mm缩短至 **55mm**（适配新的履带内侧净距60mm）。
  - 收集盒内部宽：从90mm缩小至 **55mm**。
  - 滚筒/扇叶轴、轮轴、车架底板全部按新宽度重新设计。
- **保留核心优势**：在缩小宽度的同时，保持V2.0的十字拍打逻辑、15°斜坡收集盒和弧形挡板设计不变，确保“拍打-导流-收集”的功能链完整。

# 第三版设计思路：窄体十字拨轮与侧面拨杆结构

## 一、设计背景与迭代动机

在第二版（V2.0）的设计中，我们采用了十字拨轮结构来应对硬质方块的收集，但在尺寸校核时发现了一个致命问题：整车宽度达到185mm，而比赛场地的桥梁宽度仅为150mm，导致机器人无法通过桥梁，严重限制了得分区域。

针对这一问题，我们在第三版中进行了**彻底的尺寸重构**，核心思路是：
1. **压缩车宽**：将整车宽度压缩至130mm，确保能轻松通过150mm宽的桥梁。
2. **侧面拨杆**：针对车体缩窄后，十字拨轮无法覆盖到的特殊区域（如墙角、洞穴口、矮墙间隙），在车身两侧附加**棍状拨杆结构**，将边缘方块拨到正前方供十字拨轮收集。

## 二、整车尺寸重构与过桥校核

根据《2026CRTC参赛手册V1.4》场地数据，桥梁宽150mm、净高130mm。为留出安全余量，车宽必须控制在140mm以内。

| 项目 | 尺寸 | 校核结果 |
| :--- | :--- | :--- |
| **整车初始长** | 280 mm | 符合≤290mm |
| **整车初始宽** | 130 mm | 符合≤195mm，且远小于桥梁150mm宽 |
| **整车初始高** | 200 mm | 符合≤210mm |
| **履带单条宽** | 35 mm | |
| **履带中心距** | 95 mm | 外宽 = 95 + 35 = 130mm |
| **履带内侧净距** | 60 mm | 十字拨轮和收集盒的极限安装空间 |
| **轮系** | 18齿驱动轮，轴距152mm | 节距12.7mm，42节履带，总长533.4mm |

**过桥校核**：整车宽130mm < 桥梁宽150mm，单侧余量10mm，可安全直线通过。

## 三、核心收集机构：十字拨轮与收集盒的窄体化

受限于履带内侧净距（60mm），十字拨轮和收集盒必须缩窄。

| 部件 | 尺寸 | 说明 |
| :--- | :--- | :--- |
| **十字拨轮外接圆直径** | Φ130 mm | 叶片末端旋转轨迹，径向半径65mm |
| **十字拨轮轴向长度** | 55 mm | 适配内侧净距60mm，两侧各留2.5mm防摩擦 |
| **叶片数量/厚度** | 4片 / 3-4 mm | 十字形对称，TPU软胶材质 |
| **十字拨轮轴心距地** | 65 mm | 叶片末端触地，能拍起40mm方块 |
| **驱动电机** | N20 1:50金属齿轮 | 扭矩2-3kg·cm，防止拍打方块时堵转 |
| **收集盒内部尺寸** | 160 × 55 × 90 mm | 可容纳4个40mm方块 |
| **收集盒入口高度** | ≥65 mm | 保证40mm方块（对角线56.5mm）通过 |
| **收集盒入口底部距地** | 65 mm | 与十字扇叶轴心齐平 |
| **底板倾斜** | 15° | 方块进去后自动滚向车尾 |

## 四、新增设计：侧面棍状拨杆结构

车体缩窄后，十字拨轮的有效收集宽度仅为55mm。为了应对特殊区域（场地角落、d1/e8台阶下的洞穴旁、矮墙限位处）的方块，我们在车架两侧附加**棍状拨杆结构**。

| 项目 | 设计参数 | 说明 |
| :--- | :--- | :--- |
| **拨杆数量** | 左右各1根 | 对称安装 |
| **安装位置** | 车架两侧，靠近履带前端或十字拨轮前方 | 向外侧斜向前方伸出 |
| **材质** | 3mm碳纤维杆 / 尼龙柱 / 3D打印杆 | 轻量化，需具备一定柔性 |
| **末端处理** | 包裹5mm硅胶软管 | 增加摩擦力，避免刮伤场地或方块 |
| **单侧伸出长度** | 25 mm | 整车总宽 = 130 + 25×2 = 180mm，符合≤195mm规则 |
| **被动/主动** | 被动式拨杆（或由小舵机驱动摆动） | 过桥时柔性弯折避让，或折叠收起 |
| **功能** | 将边缘方块拨到车头正前方，交给十字拨轮拍打收集 | 解决场地死角方块的收集难题 |

**设计亮点**：拨杆采用**柔性材料+末端硅胶**，即使在过桥时与桥面发生干涉，也能自然弯曲通过，不会卡死导致机器人失控。

## 五、电控与动力系统适应性调整

| 系统 | 选型 | 备注 |
| :--- | :--- | :--- |
| **履带驱动** | TT马达 1:120 ×2 + DRV8833 ×2 | 左右独立驱动，差速转向 |
| **十字拨轮驱动** | N20 1:50 ×1 + DRV8833 ×1 | 逆时针旋转（从右侧看），下沿向后拍打 |
| **侧面拨杆** | 暂不增加电机，被动式设计 | 如需主动控制，可增加SG90舵机 |
| **主控** | STM32F103C8T6 | 官方指定主控 |
| **遥控** | PS2无线手柄（可对频锁定款） | 左摇杆控制履带，L1/L2控制十字拨轮 |
| **电源** | 18650电池 ×2串联（7.4V） | 每台仅允许1个供电模块 |

3. **过桥模拟**：用纸板搭建150mm宽的“桥”，测试整车能否顺利通过。

5. **电控联调**：完成PS2手柄控制履带、十字拨轮的底层代码。
