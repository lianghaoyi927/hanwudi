## 1. 第一次组会：方案确定与国庆任务分工

### 1.1 会议基本信息

| 项目 | 内容 |
|---|---|
| 会议时间 | 2026年9月30日 |
| 会议主题 | 机器人方案确定与国庆期间任务分工 |
| 记录人 | 梁皓贻 |
| 参会人员 | 全队成员 |
| 会议目标 | 明确整体方案、两台车分工、国庆期间各组任务 |

### 1.2 会议核心结论

本次组会明确了参赛机器人的整体方案与国庆期间的工作安排：

1. **驱动形式**：采用**履带驱动**。
2. **收集形式**：采用**十字拨轮拍打收集**（会议讨论时曾提“滚轮收集”，后续经方案迭代，最终确定为十字拨轮）。
3. **机器人数量**：确定制作**两台机器人**：
   - **一号机器人**：负责平台、地面的方块快速收集。
   - **二号机器人**：负责高处置物架和附属高台上的方块收集。
4. **总体目标**：国庆假期结束之前，完成小车的**实物制作**。

### 1.3 方案确定说明

本次组会确定的核心方向，与后续底盘、收集系统的迭代设计保持一致：

| 方向 | 会议结论 | 后续迭代情况 |
|---|---|---|
| 驱动形式 | 履带驱动 | 与《底盘行走系统设计文档》一致 |
| 收集形式 | 原提“滚轮收集” | 经滚轮→十字拨轮→窄体十字拨轮三次迭代，最终确定为窄体十字拨轮+侧面拨杆 |
| 机器人数量 | 2台 | 与后续电控、视觉、串口分工一致 |

## 2. 机器人尺寸与结构要求

### 2.1 功能描述

本板块记录机器人尺寸与结构的规则约束，作为后续底盘、收集、辅助系统设计的硬性边界。

### 2.2 规则尺寸要求

根据比赛规则，对小车尺寸进行了调整：

- 调整了机器人的**长度、宽度和高度**，使其符合规则要求。
- 重点确保机器人能够**通过桥梁**。

需满足规则中的初始尺寸与变形尺寸限制：

| 项目 | 规则限制 | 本队设计值 |
|---|---|---|
| 初始长 | ≤290mm | 280mm |
| 初始宽 | ≤195mm | 130mm（含拨杆180mm） |
| 初始高 | ≤210mm | 200mm |
| 变形尺寸 | 长宽高不得大于445×400×450mm，或满足直径550mm球体范围内的变形与移动限制 | 遵守规则 |
| 重量 | ≤2.0kg | 目标≤1.8kg |

### 2.3 尺寸约束的连锁影响

由于桥梁宽度仅为150mm，整车宽必须压缩到150mm以内。这一约束直接影响了：
- 履带中心距从150mm压缩到95mm；
- 十字拨轮轴向长度从110mm缩短到55mm；
- 收集盒内部宽从90mm缩小到55mm。

## 3. 国庆期间各组任务与分工

### 3.1 机械组任务

**截止时间：** 10月5日之前

**主要任务：**
- 解决**履带底盘装配**问题。
- 解决**电机装配**问题。
- 协助电控组进行**排线**工作。
- 配合完成机器人整体结构搭建，确保国庆结束前能够做出实物小车。

**重点关注：**
- 履带底盘与电机的安装可靠性。
- 结构强度，避免比赛冲撞导致解体。
- 布线合理，避免线路过度裸露。
- 为后续功能模块预留安装区。

### 3.2 电控组任务

**主要任务：**
- 完成**电源管理**模块。
- 完成**电机驱动**模块。
- 与机械组配合完成排线与调试。
- 确保底盘运动控制可用，最终能够使用PS2手柄控制机器人运动。

**需要实现的基础功能方向：**
- GPIO、PWM使用。
- 电机、舵机转动控制。
- FreeRTOS使用与工程结构设计。
- SPI以及PS2手柄使用。

**特别注意：**
- 每台机器人仅允许安装**1个供电模块**，额定电压不超过**7.4V**。
- 指定使用**18650电池**。

### 3.3 视觉组任务

**主要任务：**
- 完成**视觉算法**测试。
- 完成**摄像头测试**。
- 与电控组、串口组配合，确保视觉数据能够正确传输和使用。

**说明：**
- 视觉部分门槛较高，赛事组委会不作统一培训，需要组内自行推进。
- 视觉功能可作为进阶功能展示，需具备创新性、可实现性和可验证性。

### 3.4 串口组任务

**主要任务：**
- 制定**串口协议**。
- 与电控组完成对接。
- 确保视觉、电控等模块之间通信稳定。

**要求：**
- 协议需明确数据格式、波特率、校验方式、收发逻辑等。
- 提前预留调试接口，方便后期联调。

## 4. 两台机器人分工细化

### 4.1 功能描述

本板块明确两台机器人的任务差异与能力要求，作为后续底盘、收集、电控方案差异化的依据。

### 4.2 分工明细

| 机器人 | 主要任务 | 关键能力 |
|---|---|---|
| 一号机器人 | 平台、地面方块快速收集 | 快速移动、地面方块识别与收集、履带底盘稳定性 |
| 二号机器人 | 高处置物架、附属高台方块收集 | 高处取物、机构伸展或抬升、精准收集 |

### 4.3 开发历程：为什么需要两台机器人分工？

- **场地差异**：比赛场地包含地面区域和高台区域，地面方块分布广、数量多，需要一台快速移动的车扫地面；高台区域方块位置高、需要精准收集，需要一台具备伸展或抬升能力的车。
- **效率最大化**：两台车同时作业，可以在5分钟内覆盖更多区域，提高白色能量单元的收集数量。
- **风险分散**：如果一台车出现故障，另一台车仍可继续收集，避免全队零分。
