## 1. 收集系统总体方案选型

### 1.1 功能描述

收集系统是机器人得分能力的核心，负责将地面的白色能量单元（30mm/40mm方块）以及可争取的黄色能量核心，通过机械方式“拍”或“卷”入后方收集盒。本系统的设计目标是：**在5分钟对局中，尽可能多地收集地面白色能量单元，同时兼顾可争取的黄色能量块，并保证被收集的方块在机器人移动、爬坡、过桥过程中不掉出。**

### 1.2 开发历程：滚轮式 vs 十字拨轮式

**第一版方案（滚轮式）：为什么被淘汰？**

第一版采用**橡胶履带底盘 + 横向圆柱滚轮 + 后方收集盒**的布局。核心收集逻辑是利用滚轮的旋转摩擦力，将地面的方块顺着导流板“卷”入后方收集盒。这一设计的好处是结构极其简单，不需要复杂的联动机构。

在建模和测试前，我们预判这一版会存在以下问题：

1. **对硬质方块的“推块效应”**：比赛和中期考核的方块是**硬质的**，且边长40mm，对角线达56.5mm。滚轮底部离地25mm时，接触点较高，极易将方块**往前推**，而不是往后卷。原因在于滚轮底部接触点过高，无法形成有效的向后摩擦力，反而将方块推离收集方向。
2. **极易卡死**：滚轮与导流板之间的间隙如果小于65mm，40mm方块会直接卡死在这里，导致TT马达堵转烧毁。这是一个致命的结构风险。
3. **动平衡缺失**：实心圆柱滚筒在高速旋转时震动较大，对轴承寿命有影响。

**结论**：滚轮式方案在硬质方块收集上存在不可接受的缺陷，必须迭代。

**第二版方案（十字拨轮）：为什么改，又为什么失败？**

为了解决“推块”和“卡死”问题，第二版放弃圆筒滚轮，改用**十字形扇叶拍打机构**。

- **核心改进**：利用十字叶片旋转时的**瞬间冲击力**，克服硬质方块的静摩擦力，直接将其“拍”进收集盒，完美解决“推块”问题。
- **尺寸规划**：十字外接圆直径Φ130mm，叶片径向半径65mm，4片对称布局，轴向长度110mm，驱动电机改用N20 1:50金属齿轮（扭矩2-3kg·cm），轴心距地65mm，叶片末端刚好触地。
- **暴露的致命问题**：在完成V2.0的三维建模和尺寸校核后，我们对照《2026CRTC参赛手册V1.4》第16页的场地数据，发现了一个致命的遗漏——**比赛场地的桥梁模块宽度仅为150mm**。而第二版设计的整车宽度为185mm（履带中心距150mm + 履带单条宽35mm）。185mm > 150mm，导致机器人**根本无法通过桥梁**，也就无法前往中央高台和对方高台区域收集方块。

**为什么“宽”是致命的？**
- **场地限制**：桥梁是连接高台与高台、抢夺中央高地黄色能量核心的**唯一通道**。如果不能过桥，机器人就被限制在了地面区域，得分上限被大幅压低。
- **规则限制**：整车宽度的规则上限是195mm，我们原设计185mm虽然在规则允许范围内，但不符合“通过150mm宽桥梁”的实际赛场需求。
- **操作风险**：即使勉强过桥，185mm的车宽在150mm桥面上，单侧仅余-17.5mm（车比桥还宽），机器人会直接卡在桥头或坠落，严重影响比赛进程。

**第三版方案（窄体十字拨轮）：如何重构？**

基于V2.0的失败教训，我们在第三版中进行了**彻底的尺寸重构**：

1. **缩小整车宽度**：将履带中心距从150mm压缩至95mm，新整车宽度 = 95 + 35 = 130mm，留出10mm单侧余量，确保能安全通过150mm宽的桥梁。
2. **自适应调整核心机构**：
   - 十字扇叶轴向长度：从110mm缩短至55mm（适配新的履带内侧净距60mm）。
   - 收集盒内部宽：从90mm缩小至55mm。
   - 滚筒/扇叶轴、轮轴、车架底板全部按新宽度重新设计。
3. **保留核心优势**：在缩小宽度的同时，保持V2.0的十字拍打逻辑、15°斜坡收集盒和弧形挡板设计不变，确保“拍打-导流-收集”的功能链完整。

**最终选型结论**：采用**窄体十字拨轮 + 侧面拨杆辅助**的收集方案，兼顾过桥能力与收集效率。

## 2. 十字拨轮机构设计

### 2.1 功能描述

十字拨轮是本系统的核心执行机构，负责将地面的方块通过旋转拍打的方式“拍”入后方收集盒。利用叶片旋转时的瞬间冲击力，克服硬质方块的静摩擦力。

### 2.2 开发历程：为什么选择N20 1:50金属齿轮电机？

- **扭矩需求**：拍打40mm硬质方块时，需要克服方块的静摩擦力。经过估算，所需扭矩约为2-3kg·cm。
- **转速需求**：转速过低无法有效拍打，过高则可能将方块拍飞。经过试验，150-200rpm是合适区间，表面线速度约1.0-1.36m/s。
- **TT马达1:48的问题**：虽然TT马达1:48转速约200rpm，但扭矩较小，拍打硬质方块时容易堵转烧毁。
- **结论**：选择N20 1:50金属齿轮电机，扭矩2-3kg·cm，满足拍打需求，且金属齿轮耐久性更好。

### 2.4 拨轮支架设计

- 左右各一个3D打印支架，固定在车架上，内嵌法兰轴承支撑拨轮轴。
- 支架高度固定，轴心距地65mm。
- 支架采用PETG材料，壁厚2mm，填充40%，兼顾强度与轻量化。

## 3. 收集盒与导流系统

### 3.1 功能描述

收集盒负责承接被十字拨轮拍入的方块，并防止方块在爬坡、颠簸过程中掉出。通过15°倾斜底板和软硅胶挡板的设计，实现方块的自动归位与防掉落。

### 3.2 开发历程：为什么入口高度要定65mm？

收集盒入口底部距地65mm，是与十字拨轮轴心齐平的高度，也是保证40mm方块能够顺利通过的关键尺寸。

- **40mm方块的对角线长度为56.5mm**（√(40²+40²) ≈ 56.5mm）。如果入口高度小于56.5mm，方块会在入口处卡住，无法进入。
- 将入口高度设定为≥65mm，留出约8.5mm的余量，即使方块以倾斜姿态进入，也能顺利通过。
- 入口底部距地65mm，与十字拨轮轴心齐平，保证被拍起的方块能够以最自然的抛物线轨迹进入收集盒。

**为什么底板要倾斜15°？**
- 方块进入收集盒后，如果不加引导，容易堆积在入口处，堵塞后续方块进入。
- 15°的倾斜角能够使方块在重力作用下自然滚向收集盒深处，最大化利用收集盒容量。
- 15°角同时兼顾了“滚动力”和“不卡死”：角度太小则滚动力不足，角度太大则方块可能滚得过快，撞击后壁导致反弹。

**为什么后壁要加软硅胶挡板？**
- 机器人爬坡或颠簸时，收集盒内的方块容易向后滚出。
- 后壁加装高40mm的软硅胶挡板，能够有效阻挡方块滚出，同时在方块进入时允许软硅胶变形通过，不影响收集。

**设计理由**：弧形挡板负责接住被十字拨轮拍飞的方块，并将其导入收集盒入口。半径80mm的弧度能够贴合拨轮叶片旋转轨迹，确保方块在被拍飞后不会偏离收集方向。

4. **侧壁光滑**：贴特氟龙胶带，减少摩擦。

## 4. 侧面拨杆辅助结构

### 4.1 功能描述

车体缩窄至130mm后，十字拨轮有效收集宽度仅为55mm，无法覆盖场地边缘、墙角、矮墙间隙等特殊区域的方块。侧面拨杆的功能是**将边缘方块拨到车头正前方，供十字拨轮拍打收集**。

### 4.2 开发历程：为什么需要侧面拨杆？

在V3.0尺寸重构后，团队发现窄体设计虽然解决了过桥问题，但收集宽度大幅缩减。原V2.0方案中，十字拨轮轴向长度110mm，有效收集宽度110mm；而V3.0缩窄至55mm，损失了一半以上的收集范围。

为了解决这个矛盾，团队经过讨论，提出两种思路：
- **思路A**：加宽拨轮，牺牲过桥能力。被否决，因为过桥是硬性门槛。
- **思路B**：保持窄体，加装侧面辅助拨杆。被采纳，因为拨杆可以在不增加核心宽度的情况下，将边缘方块“拨”到拨轮前方。

拨杆采用**柔性材料+末端硅胶**，即使在过桥时与桥面发生干涉，也能自然弯曲通过，不会卡死导致机器人失控。

### 4.3 拨杆参数

| 项目 | 规格 |
|---|---|
| 数量 | 左右各1根 |
| 材质 | 3mm碳纤维杆 / 尼龙柱 / 3D打印杆 |
| 末端处理 | 包裹5mm硅胶软管 |
| 单侧伸出长度 | 25mm |
| 整车含拨杆总宽 | 130 + 25×2 = 180mm（符合≤195mm） |
| 安装位置 | 车架两侧，靠近履带前端或拨轮前方 |
| 驱动方式 | 被动式（柔性材料自然弯曲）或小舵机主动摆动 |
| 功能 | 将边缘方块拨到车头正前方，交给十字拨轮拍打收集 |

**设计亮点**：拨杆采用柔性材料+末端硅胶，过桥时如与桥面干涉可自然弯曲通过，不会卡死。

## 6. 下一步计划（V4.0）

1. **3D打印验证**：按V3.0尺寸打印车架、十字拨轮、收集盒小样。
2. **侧面拨杆测试**：手动测试被动拨杆能否有效将边缘方块拨入拍打范围。
3. **过桥模拟**：用纸板搭建150mm宽的“桥”，测试整车能否顺利通过。
4. **拍打收集测试**：放40mm硬质方块，测试十字拨轮能否单次拍入收集盒。
5. **电控联调**：完成PS2手柄控制履带、十字拨轮的底层代码。
