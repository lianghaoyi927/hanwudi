## 1. 设计总览

### 1.1 设计目标

| 目标 | 说明 |
|---|---|
| 通过性 | 能上300mm高台（坡比0.5）、150mm台阶，可通过150mm宽桥梁 |
| 收集效率 | 5分钟内收集6-9个30mm白色能量单元，中期考核可拍入40mm硬质方块 |
| 稳定性 | 从180mm自由落体无零件掉出 |
| 成本 | 两台总成本控制在400元内 |
| 重量 | 每台≤1.8kg，留200g余量 |
| 尺寸 | 初始长≤290，宽≤195，高≤210mm；实际宽130mm（含拨杆180mm） |

### 1.2 系统组成

```

机器人
├── 底盘系统
│   ├── 窄体履带 ×2
│   ├── 驱动轮 ×2
│   ├── 从动轮 ×2
│   ├── 轮轴 ×4
│   ├── 法兰轴承 ×8
│   └── TT马达1:120 ×2
├── 收集系统
│   ├── 十字拨轮（Φ130，轴向55mm）
│   ├── 拨轮轴
│   ├── N20 1:50金属齿轮电机 ×1
│   ├── 弧形导流挡板
│   └── 收集盒（160×55×90mm）
├── 辅助系统
│   ├── 侧面拨杆 ×2
│   ├── SG90舵机 ×1（挡板）
│   └── 软硅胶挡板
└── 电控系统
├── STM32F103C8T6
├── DRV8833 ×3
├── PS2手柄+接收器
├── 无线继电器
├── DC-DC降压模块
└── 18650电池 ×2

```

### 1.3 设计原则

1. **窄体优先**：整车宽严格控制在130mm，确保通过150mm桥梁。
2. **低质心**：电池、主控、驱动放在履带之间、拨轮后方，距地60-80mm。
3. **低入口**：收集盒入口底部距地65mm，保证40mm方块对角线顺利通过。
4. **模块化**：十字拨轮、收集盒、导流板均可独立拆卸更换。
5. **可维护**：线路走线槽，杜邦线用扎带固定，避免脱落。
6. **轻量化**：3D打印件壁厚1.5-2mm，非受力件用PLA，受力件用PETG。

## 6. 侧面拨杆辅助结构

### 6.1 设计目的

车体缩窄至130mm后，十字拨轮有效收集宽度仅为55mm，无法覆盖场地边缘、墙角、矮墙间隙等特殊区域的方块。为此在车身两侧附加棍状拨杆，将边缘方块拨到车头正前方，供十字拨轮拍打收集。

### 6.2 拨杆参数

| 项目 | 规格 |
|---|---|
| 数量 | 左右各1根 |
| 材质 | 3mm碳纤维杆 / 尼龙柱 / 3D打印杆 |
| 末端处理 | 包裹5mm硅胶软管 |
| 单侧伸出长度 | 25mm |
| 整车含拨杆总宽 | 130 + 25×2 = 180mm（符合≤195mm） |
| 安装位置 | 车架两侧，靠近履带前端或拨轮前方 |
| 驱动方式 | 被动式（柔性材料自然弯曲）或小舵机主动摆动 |
| 功能 | 将边缘方块拨到车头正前方，交给十字拨轮拍打收集 |

**设计亮点**：拨杆采用柔性材料+末端硅胶，过桥时如与桥面干涉可自然弯曲通过，不会卡死。

### 7.3 接线定义

| STM32引脚 | 功能 | 连接 |
|---|---|---|
| PA0 | PWM | 左履带DRV8833 IN1 |
| PA1 | PWM | 左履带DRV8833 IN2 |
| PA2 | PWM | 右履带DRV8833 IN1 |
| PA3 | PWM | 右履带DRV8833 IN2 |
| PA4 | PWM | 拨轮DRV8833 IN1 |

### 7.4 供电模块规则

- 每台机器人**仅1个供电模块**，有且仅有一个输出接口。
- 电池盒输出→无线继电器→主控/驱动，算1个供电模块。
- 不要加转接板变成多个接口。
- 无线继电器接在电池与底盘电源之间，确保10m内能切断底盘电源。

## 9. 供电与安全

### 9.1 电源规格

| 项目 | 规格 |
|---|---|
| 电池 | 18650 ×2串联，7.4V |
| 容量 | 2000-3000mAh |
| 放电倍率 | ≥5C |
| 供电模块 | 1个，输出接口1个 |
| 降压 | 7.4V→5V，给主控和舵机 |
| 电机供电 | 7.4V直供DRV8833 |

### 9.2 安全规范

1. 电池不得短路、反接、过放。
2. 无线继电器必须能在10m内切断底盘电源。
3. 线路不得过度裸露，用扎带固定。
4. 不得携带尖锐物体、易燃易爆化学物质。
5. 不得加装易损坏对方机器人的装置。
6. 车底拖一根细铜丝接地，防止静电烧毁元件。

### 9.3 检录要求

- 机器人从150-200mm自由落体，无零件掉出。
- 无线继电器断电功能正常。
- 尺寸、重量符合规范。
- 供电模块数量正确。

## 11. 装配流程

### 11.1 装配顺序

```

1. 车架底板打印完成
2. 安装履带轮系（驱动轮、从动轮、轴承、轴）
3. 安装履带，调节张紧
4. 安装TT马达1:120 ×2，连接驱动轮
5. 安装十字拨轮支架、拨轮轴、十字拨轮
6. 安装N20电机，联轴器连接拨轮轴
7. 安装弧形导流板
8. 安装收集盒、舵机、挡板
9. 安装侧面拨杆
10. 安装电控板、电池、主控、DRV8833
11. 接线、调试
12. 整机测试

```

### 11.2 装配注意事项

1. 履带张紧度：中部下垂≤5mm。
2. 十字拨轮与弧形挡板间隙：≥65mm，必须过40mm方块。
3. 收集盒入口底部距地：65mm。
4. 线路用扎带固定，避免卷入履带或拨轮。
5. 电池固定在车架中心，远离拨轮和履带。
