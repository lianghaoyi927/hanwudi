# 第二辆车（视觉叉车特种车）核心选型与成本预算


## 1. 第二辆车核心部件选型依据

### 1.1 功能描述

二号车的核心定位是**“精准收集高台、置物架和洞穴内的方块”**。为了完成这种复杂的特种作业，本车选型采取“底盘复用+特种机构定制+视觉进阶”的策略。

### 1.2 开发历程：为什么这么选？

- **底盘为何复用麦轮？** 一号车的麦轮运动学代码已经跑通，二号车直接复制，能省去大量电控调试时间，且麦轮的全向移动能力更适合在狭窄的高台边缘微调姿态。
- **为什么选用叉车+滑轨结构？** 相比于一号车的拨轮，叉车能通过前后伸缩和上下俯仰，直接够到高处的方块；下部延长的叉齿也能深入洞穴勾取方块。
- **为什么选用双舵机驱动？** 叉车机构不需要复杂的全向机械臂，底部的三个主叉齿只需一组舵机控制俯仰和伸缩，辅以一个灵活的上叉。舵机控制逻辑简单，重量轻，能大幅降低故障率。
- **为什么引入视觉系统？** 高台和洞穴的视野盲区极大，纯靠肉眼操作容易失误。团队自费引入视觉模块，操作手可通过屏幕第一视角（FPV）锁定方块，大幅提升精准度。

### 1.3 核心部件选型清单

| 部件类别 | 最终选型 | 选型理由与说明 | 来源方式 |
|---|---|---|---|
| **底盘系统** | 60mm 麦克纳姆轮 ×4 + TT马达 1:120 | 复用一号车成熟的开环解算代码，全向移动方便对准目标。 | **借用** |
| **叉车驱动** | 大扭矩舵机（如 MG996R） ×2 | 负责控制主叉齿的俯仰和滑轨的前后伸缩。 | **借用** |
| **上叉驱动** | SG90 9g 舵机 ×1~2 | 负责上部灵活叉的旋转，专攻置物架方块。 | **借用/复用** |
| **视觉主控** | 树莓派 / 高级视觉主控板 | 运行 Python/OpenCV，处理图像并计算目标坐标。 | **团队自费** |
| **视觉传感器** | USB 免驱高清摄像头 | 安装于叉车上方，提供第一人称视角与图像输入。 | **团队自费** |
| **电控核心** | STM32F103C8T6 核心板 | 接收视觉数据，控制底盘运动和舵机动作。 | **复用前期采购** |
| **电机驱动** | DRV8833 模块 ×2 | 驱动麦轮底盘。 | **复用前期采购** |
