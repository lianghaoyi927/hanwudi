# 行走方式选型讨论记录：轮子 vs 履带

## 一、背景

机器人新生赛需要确定底盘行走方式。团队经过前两天讨论，重点对比了**轮式**和**履带式**两种方案，主要从**稳定性**和**爬坡、上台阶能力**两个维度评估，最终确定采用**履带**方案。

## 二、方案对比

| 对比维度 | 轮式 | 履带式 |
|---------|------|--------|
| 稳定性 | 一般。按照要求进行 | 较好。履带接地面积大、重心低，行驶平稳，越障时姿态更可控 |
| 爬坡能力 | 较弱。受轮胎抓地力和轮径限制，坡度稍大容易打滑 | 较强。履带与地面接触面积大、抓地力强，能适应较陡坡面和松软地面 |
| 越障能力 | 受轮径限制，跨越台阶、沟槽能力弱 | 可跨越较小台阶和沟槽，地形适应性强 |
| 转向灵活性 | 好，可原地转向（差速轮）或小半径转向 | 一般，靠两侧差速转向，摩擦大、转向阻力高 |
| 结构复杂度 | 较低，结构简单、易装配维护 | 较高，涉及履带、驱动轮、张紧轮、负重轮等 |
| 速度 | 较快 | 相对较慢 |
| 成本/维护 | 较低，轮胎易更换 | 较高，履带易磨损、需张紧调整 |

## 三、讨论要点

1. **稳定性**：比赛场地可能存在坡道、障碍或不平整地面。轮式在越障和急转时容易失稳；履带接地面积大、重心低，整体更稳。
2. **爬坡能力**：这是本次选型的核心考量。履带抓地力明显优于轮子，在坡面、松软或湿滑地面上不易打滑，更能满足比赛可能的爬坡要求。
3. **代价**：履带方案结构更复杂、转向阻力大、速度偏慢、维护成本更高，但综合比赛任务需求，这些代价可以接受。

## 四、结论

综合**稳定性**和**爬坡能力**两项关键指标，团队最终选择 **履带式行走方案**。

后续需要在结构设计中重点解决：
- 履带张紧机构的设计与调整
- 履带驱动的转弯方式：差速转弯还是单边刹停？
- 重心布置，进一步保证爬坡和越障时的稳定
